# 交互与宿主验收

本文区分三类验证：代码测试、模拟 DSH 服务的真实浏览器测试、真实 DSH 宿主验收。它们不能互相替代。浏览器基线使用真实 Chromium、ReactDOM、插件构建产物及用户点击，不使用假 hooks 或源码字符串断言；但仓库读取、模型调用和原生更新均为可控模拟服务。

## 运行浏览器基线

准备 Node.js 22 或更新版本及锁定依赖，首次运行需安装测试浏览器：

```sh
npm ci --include=dev --ignore-scripts
npx playwright install chromium
npm run test:browser
```

`test:browser` 先构建插件再执行 Playwright。已构建且没有源码变更时，可单独执行 `npx playwright test`。测试默认启动专用 `http://127.0.0.1:4178` 夹具，端口占用即失败，不复用未知服务；结束时 Playwright 负责关闭服务。它不是 DSH 页面，不替换或更新已有 GUI，也不安装插件。首次下载 Chromium 需要网络；测试本身不调用模型服务、npm 更新接口或真实仓库。

可设置 `DSH_BROWSER_CHANNEL=msedge` 使用已安装 Edge。`DSH_BROWSER_OUTPUT` 可指定测试产物目录；默认保存在操作系统临时目录的 `dsh-code-report-browser-results`，失败时保存截图和 trace，视口用例附带截图。不要并行运行两套使用同一端口或产物目录的测试。

源码入口：[Playwright 配置](<../playwright.config.mjs>)、[夹具服务器](<../test/browser/server.mjs>)、[真实 ReactDOM 适配器](<../test/browser/harness.jsx>)、[交互用例](<../test/browser/report.spec.mjs>)。

## 自动化覆盖及通过标准

| 场景 | 通过标准 |
| --- | --- |
| 扫描、选择、采集、生成、下载 | 真实点击与重渲染完成；下载内容与界面报告一致 |
| 模型授权 | 未勾选时生成禁用、模型派发为零；失败重试必须再次勾选 |
| 生成响应丢失 | 自动只读恢复已完成结果；pending 期间阻止再次生成，手动恢复不增加模型调用；切会话后恢复句柄仍在，未知结果期间禁新采集和安装 |
| 成功重新采集后模型失败 | 上一次模型报告仍可查看、下载，不被新本地证据永久覆盖 |
| 报告安全展示 | 报告中的 script 作为纯文本，不执行 |
| 本地 refs、上下文与分批 | refs 不 fetch，显式选择工作区/A/B 上下文进入请求；预算或路由改变清除许可，更新计划不调用模型 |
| 进度连接失联 | 显示结果尚未知，不重复派发仍在进行的任务 |
| 草稿变化与新采集失败 | 旧报告保留、标记过时，仍可导出 |
| 快照到期 | 到期禁生成，重采集后不继承发送确认 |
| 切换会话 | 报告不串会话；返回原会话只恢复报告，不恢复活动快照或确认；不默认持久化报告正文 |
| 取消及迟到响应 | 模拟服务忽略取消时，迟到结果也不能覆盖旧报告或新会话 |
| 无工作区、版本不匹配 | 不派发扫描、采集或模型请求 |
| 更新重启屏障 | 模拟宿主返回需重启后，切会话仍禁止业务与重复安装 |
| 320 / 680 / 1280 像素 | 500 行和长路径可筛选，键盘 Space 可选择，焦点可达，无整页横向溢出；截图供人工检查 |

该基线不是完整无障碍认证、全部浏览器兼容性证明或性能基准；视口断言及截图也不能证明所有主题、缩放、屏幕阅读器组合均可用。

## 真实 DSH 宿主验收清单

以下项目必须另行在明确授权的独立测试 profile 中执行。不得将浏览器夹具通过写成这些项目通过；不得因此安装到日常环境、自动重启宿主或发送业务源码。每项记录通过、失败或未执行，禁止留空当作通过。

### 环境及证据

- [ ] 记录提交、插件包版本与 SHA-256、DSH 版本、系统、浏览器版本、测试 profile 和日期。
- [ ] 先备份测试配置，确认测试仓库不含真实凭据；模型测试另获发送范围和费用授权。
- [ ] 每个失败保留操作步骤、预期/实际、阶段、脱敏 console/RPC 错误及截图。不要上传完整源码或令牌。

### 加载与版本门禁

- [ ] 通过宿主原生插件管理安装已校验测试包，按宿主要求手动重启，刷新原宿主 URL 后侧栏入口可用。
- [ ] 前后台版本/协议一致；模拟或可控复现不一致时，业务请求被阻止且恢复说明正确。
- [ ] 无工作目录、会话切换、离开再返回、刷新页面均无白屏、未处理异常或跨会话结果。

### 真实仓库及结果保全

- [ ] 临时 Git 仓库：分支空版本固定不同分支最新提交；显式 SHA/标签正确；未提交修改不进入历史差异。
- [ ] 临时 SVN 仓库：历史访问须授权，版本空白及显式 r 版本均固定正确端点；不修改工作副本。HTTP/HTTPS 访问及认证另行验证。
- [ ] A/B 固定版本源码与当前工作区源码来源清楚；删除文件、二进制、编码、越界、敏感路径及超限错误明确。
- [ ] 修改草稿、新采集失败或取消后旧报告可下载；到期可重新采集，发送许可不继承。
- [ ] 320 / 680 / 1280、长路径、大列表、键盘、深浅主题和常用缩放人工检查无遮挡、无法操作或焦点丢失。

### 模型、容量与故障

- [ ] 未确认范围/路由时零模型派发；明确授权后调用正确提供方及模型。
- [ ] 验证真实模型结构化输出、引用、接口变化与 QA 建议质量；引用有效不等于结论正确，逐项人工复核。
- [ ] 分片数量、估算预算、已完成/失败/未分析范围明确；部分失败不冒充完整报告，再次确认后只重试失败片。
- [ ] 取消前派发为零；执行中取消、断网、超时、模型截断/非法输出的结果诚实，不能承诺撤回已发请求或不计费。

### 原生更新（单独授权）

- [ ] 无活动报告任务才允许安装；目标版本固定且不改变原启用状态，不绕过宿主安全策略。
- [ ] 明确失败可恢复；需重启、已应用或结果未知时阻止重复安装。切会话不解除屏障。
- [ ] 断线后先核查原生管理器，不自动重放安装；保存工作后由操作者手动重启并确认真实运行版本。
