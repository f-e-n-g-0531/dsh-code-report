# 交互与宿主验收

本文区分三类验证：代码测试、模拟 DSH 服务的真实浏览器测试、真实 DSH 宿主验收。它们不能互相替代。浏览器基线使用真实 Chromium、ReactDOM、插件构建产物及用户点击，不使用假 hooks 或源码字符串断言；但仓库读取、模型调用和原生更新均为可控模拟服务。

## 运行浏览器基线

准备 Node.js 22 或更新版本及锁定依赖，首次运行需安装测试浏览器：

```sh
npm ci --include=dev --ignore-scripts
npx playwright install chromium
npm run test:browser
```

`test:browser` 先构建插件再执行 Playwright。已构建且没有源码变更时，可单独执行 `npx playwright test`。测试默认启动专用 `http://127.0.0.1:4178` 夹具，端口占用即失败，不复用未知服务；结束时 Playwright 负责关闭服务。它不是 DSH 页面，不替换或更新已有 GUI，也不安装插件。首次下载 Chromium 需要网络；测试本身不调用模型服务、npm 更新接口或真实仓库。

可设置 `DSH_BROWSER_CHANNEL=msedge` 使用已安装 Edge。`DSH_BROWSER_OUTPUT` 可指定测试产物目录；默认保存在操作系统临时目录的 `dsh-code-report-browser-results`，失败时保存截图和 trace，视口用例附带截图。不要并行运行两套使用同一端口或产物目录的测试。

CI 在标签或手动触发时另跑 Ubuntu / Node 24 浏览器任务，发布依赖它与四组代码测试完成；自动保存失败截图和 trace。浏览器任务仍是模拟服务验收，不是线上宿主验收。

源码入口：[Playwright 配置](<../playwright.config.mjs>)、[夹具服务器](<../test/browser/server.mjs>)、[真实 ReactDOM 适配器](<../test/browser/harness.jsx>)、[交互用例](<../test/browser/report.spec.mjs>)。

## 自动化覆盖及通过标准

| 场景 | 通过标准 |
| --- | --- |
| 扫描、选择、采集、生成、下载 | 真实点击与重渲染完成；本地证据下载保持原文，正式模型报告下载按五节正文规则转换，插件内原始报告与附录保留 |
| 模型授权 | 未勾选时生成禁用、模型派发为零；失败重试必须再次勾选 |
| 生成响应丢失 | 自动只读恢复已完成结果；pending 期间阻止再次生成，手动恢复不增加模型调用；切会话后恢复句柄仍在，未知结果期间禁新采集和安装 |
| 成功重新采集后模型失败 | 上一次模型报告仍可查看、下载，不被新本地证据永久覆盖 |
| 报告安全展示 | 界面不执行 script；导出对标题、路径、限制、模型文本等不可信字段统一转义，不因 Markdown 阅读器启用 HTML 而生成活动内容；库级 full 的原始 diff 保留在围栏；默认摘要主报告不嵌全部 diff，清单不冒充全文归档 |
| Git 来源、refs、上下文与摘要 | 默认 remote/origin，远端查询/采集明确提示联网；显式 local 才离线。请求带模式与远端名，预览展示来源、远端与观察时间；工作区/A/B 上下文先完整采集，模型仅收预算内所选元数据与片段；预算或路由改变清除许可，更新计划不调用模型 |
| Git 配置迁移与模式切换 | 旧配置缺字段迁 remote/origin，不伪造本地分支为远端默认；切模式或远端名清 refs/预览/发送许可并保留 A/B，远端失败无本地回退 |
| 文件夹源码契约模拟 | 原始目录输入保持在 contextPaths 请求；模拟预览返回多个实际文件及排除计数，授权前清单与限制可见、模型派发为零；不证明真实文件系统展开 |
| 大规模范围契约模拟 | 超过旧路径数量和分析片数门槛仍可本地采集（分析片数门槛仅针对库级 full 回归），完整本地文件/字节与摘要发送/未发送计数分别显示；默认预算 64000、单次 payload，不静默全量拆片；未确认模型派发为零，确认绑定预览与计划，不证明真实大仓库性能或全文语义覆盖 |
| 单次摘要与归档 | 明确一次插件派发且无自动重试，生成物正文不发送；必要统计超预算拒绝规划，不能静默漏项目。摘要主报告不内嵌全部 diff；完整 snapshot 仅内存 TTL，保存配置或下载主报告不当作原始证据已归档 |
| 进度连接失联 | 显示结果尚未知，不重复派发仍在进行的任务 |
| 草稿变化与新采集失败 | 旧报告保留、标记过时，仍可导出 |
| 快照到期 | 到期禁生成，重采集后不继承发送确认 |
| 切换会话 | 报告不串会话；返回原会话只恢复报告，不恢复活动快照或确认；不默认持久化报告正文 |
| 取消及迟到响应 | 模型任务由插件实例持有；切会话或离开面板不取消任务，迟到成功仅写回原 session+cwd；显式取消仍保留身份供只读核对 |
| 本地停止与结果未知 | stopped 后显示实际派发次数与可能费用；pending、正文被淘汰、任务过期或恢复失败保持未知，不按错误文案解锁；放弃恢复只标记意图，不解除未知任务屏障 |
| 报告业务与安装竞态 | 同实例任务租约涵盖扫描、采集、分析、两种来源的 refs 与安装；其他会话不能绕过，未知安装继续阻断；下载和只读恢复不依赖新业务门禁 |
| 无工作区、版本不匹配 | 不派发扫描、采集或模型请求 |
| 更新重启屏障 | 模拟宿主返回需重启后，切会话仍禁止业务与重复安装 |
| 320 / 680 / 1280 像素 | 500 行和长路径可筛选，键盘 Space 可选择，焦点可达，无整页横向溢出；截图供人工检查 |

该基线不是完整无障碍认证、全部浏览器兼容性证明或性能基准；视口断言及截图也不能证明所有主题、缩放、屏幕阅读器组合均可用。

## 真实 DSH 宿主验收清单

以下项目必须另行在明确授权的独立测试 profile 中执行。不得将浏览器夹具通过写成这些项目通过；不得因此安装到日常环境、自动重启宿主或发送业务源码。每项记录通过、失败或未执行，禁止留空当作通过。

### 环境及证据

- [ ] 记录提交、插件包版本与 SHA-256、DSH 版本、系统、浏览器版本、测试 profile 和日期。
- [ ] 先备份测试配置，确认测试仓库不含真实凭据；模型测试另获发送范围和费用授权。
- [ ] 每个失败保留操作步骤、预期/实际、阶段、脱敏 console/RPC 错误及截图。不要上传完整源码或令牌。

### 加载与版本门禁

- [ ] 通过宿主原生插件管理安装已校验测试包，按宿主要求手动重启，刷新原宿主 URL 后侧栏入口可用。
- [ ] 前后台版本/协议一致；模拟或可控复现不一致时，业务请求被阻止且恢复说明正确。
- [ ] 无工作目录、会话切换、离开再返回、刷新页面均无白屏、未处理异常或跨会话结果。

### 真实仓库及结果保全

- [ ] 临时 Git 远端：远端分支领先本地时仍取远端；origin/name、refs/remotes/origin/name、显式标签、SHA/HEAD~ 与远端 HEAD 正确解析，缺分支失败不回退本地。读取后业务 objects/refs/worktree 不变，临时目录清理。HEAD 在查询/抓取间移动时失败重采，观察时间不是全仓原子快照。
- [ ] 远端传输取消：以真实受控 SSH/helper 子进程树验证停止本地自有传输进程树并清理临时目录；等待 close，不遗留本地后代或悬挂请求。不保证远端服务器撤销请求；模拟浏览器取消不替代该测试。
- [ ] 显式本地模式：只读已有分支/对象；partial clone 缺对象应失败、不自动 fetch。旧 RPC 无 mode 仍本地兼容，但 UI 旧配置恢复默认 remote/origin，网络提示不可隐藏。
- [ ] 源仓库 local core.sshCommand/ssh.variant 与 credential/http 有效配置，以及显式 SSH 环境覆盖，在受控临时远端进程可用；URL rewrite/hooks/remote uploadpack/ext/任意 remote helper 不继承，其他 GIT_ 注入仍清除，本地严格读取不变。相对 -i 不自动改写，仍相对临时目录；推荐绝对路径，不把该限制写成已自动修复。
- [ ] 公网 HTTP/HTTPS/SSH 及非交互认证另行授权验证。仓库与用户认证程序均为可信可执行配置；错误仅固定分类提示，不泄露 URL、凭据或密钥路径，不自动关闭主机/TLS 校验。不把此策略称为 OS 沙箱、保证不执行用户 helper 或证明用户凭据错误。
- [ ] 临时 SVN 仓库：历史访问须授权，版本空白及显式 r 版本均固定正确端点；不修改工作副本。HTTP/HTTPS 访问及认证另行验证。
- [ ] A/B 固定版本源码与当前工作区源码来源清楚；固定版本仍仅文件。工作区文件与目录（含根 `.`）可混合，递归后实际清单与排除计数在授权前可见；点前缀隐藏、敏感、依赖、构建、缓存路径、链接及非普通文件被跳过，显式敏感路径拒绝；不按 Windows Hidden 属性筛选。
- [ ] 大规模更新超过旧路径、文件、单文件大小、总证据、目录条目/目录/深度及分片门槛仍完整采集、规划，预览展示实际文件、字节及片数，覆盖统计不遗漏。无固定规模上限不代表无限内存或模型能力；记录可用资源、耗时和峰值内存。无 BOM 的 NUL、损坏 BOM UTF-16、其他不符合源码编码支持条件或读取失败导致整次失败，不静默跳过或截断；删除文件、越界等错误明确，取消确实停止后续读取。
- [ ] 修改草稿、新采集失败或取消后旧报告可下载；到期可重新采集，发送许可不继承。
- [ ] 320 / 680 / 1280、长路径、大列表、键盘、深浅主题和常用缩放人工检查无遮挡、无法操作或焦点丢失。

### 模型、容量与故障

- [ ] 未确认范围/路由时零模型派发；明确授权后调用正确提供方及模型。
- [ ] 验证真实模型结构化输出、引用、接口变化与 QA 建议质量；引用有效不等于结论正确，逐项人工复核。
- [ ] 默认单次摘要的预算、已发送/未发送范围及派发次数明确；失败不在同次生成中追加请求，显式重试须重新确认且可能计费。库级 full 策略另验分片数量、已完成/失败/未分析范围及同计划、同路由下已校验片复用；部分失败不冒充完整报告。
- [ ] 取消前派发为零；执行中取消、断网、超时、模型截断/非法输出的结果诚实，不能承诺撤回已发请求或不计费。核对结构化执行事实，不从错误前缀推断；同 operationId 重放不新增派发，backendInstanceId 改变或记录不可用时仍提示未知。
- [ ] SVN 属性变化、新增/删除空目录及根属性的覆盖范围可见；没有文本不等于没有变化，无法精确归属的块不按文件顺序猜测。
- [ ] 升级后旧格式计划不复用；库级 full 策略的 checkpoint 另须校验格式，同版本也须匹配分片 payload 哈希与路由。

### 原生更新（单独授权）

- [ ] 无活动报告任务才允许安装；目标版本固定且不改变原启用状态，不绕过宿主安全策略。
- [ ] 明确失败可恢复；需重启、已应用或结果未知时阻止重复安装。切会话不解除屏障。
- [ ] 断线后先核查原生管理器，不自动重放安装；保存工作后由操作者手动重启并确认真实运行版本。
