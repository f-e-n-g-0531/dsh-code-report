# 开发指南

本文面向需要修改插件或运行测试的开发者。只想使用插件，请看 [使用说明](<../README.md>)。

## 准备环境

需要 Node.js 22 或更新版本、npm、Git。运行 SVN 集成测试还需要 svn 和 svnadmin 命令。测试会创建临时仓库，不使用你的业务仓库。

## 安装依赖与检查

在项目根目录执行：

~~~sh
npm ci --include=dev --ignore-scripts
npm run check
npm run verify:package
npm run test:install
~~~

- check：编译界面并运行自动化测试。
- verify:package：检查安装包包含的文件，生成安装包及 SHA-256 校验值。
- test:install：在临时目录安装刚生成的包，检查服务端入口与客户端加载。

安装测试使用模拟 DSH 接口。测试通过不表示已在真实 DSH 页面中验证，也不表示真实模型分析质量通过验收。这些命令不会安装到你的日常 DSH 环境。

## 代码入口

- [宿主入口](<../index.mjs>)：从当前会话取得工作目录，处理预览、生成与进度请求。
- [差异采集](<../src/collect.mjs>)：读取 Git / SVN 差异和用户选择的源码。
- [路径检查](<../src/paths.mjs>)：限制文件读取范围。
- [命令执行](<../src/process.mjs>)：执行有输出大小和超时限制的命令。
- [报告生成](<../src/report.mjs>)：调用模型并整理 Markdown。
- [界面](<../src/client.jsx>)：项目配置、发送确认、进度和报告下载。
- [测试](<../test/report.test.mjs>)：隔离仓库、源码读取、会话隔离和模型调用约束。

## 资源限制

一次最多 12 个项目，附带源码最多 20 个文件，单文件 128 KiB；采集结果 JSON 限制 1 MiB。单个命令输出限制 4 MiB，超时 60 秒；单次执行请求超时 240 秒。超过限制会报错，不静默截断。

预览保存在宿主内存中，10 分钟后失效。模型分析成功后不能复用同一次预览；失败可重试，可能再次计费。

## 提交与发布

自动测试仅由版本标签或手动操作触发，普通分支推送与拉取请求不触发。发布顺序与异常处理见 [发布指南](<RELEASING.md>)。
